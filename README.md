
Hatches Plus
=======

Adds specialized hatches to Modern industrialization. 

As of 0.0.1:
- Infinite Water Input Hatch - gives multiblocks that accept fluid input hatches to access to infinite water. 
- Stocking Item Hatches - for high-throughput multi block machines. Has 9 channels for 9 types of item. Can accept or store 4096 of each item type.
